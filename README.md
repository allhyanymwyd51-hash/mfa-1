# MFA 1

**MFA 1** لعبة أندرويد أصلية؛ محرك اللعبة والرسم والتحكم مكتوبة بـ **C++ وOpenGL ES** على Android NativeActivity. لا تحتوي على صفحة ويب أو JavaScript أو موسيقى. الاسم الظاهر في التطبيق هو MFA 1.

## اللعب

- يبدأ اللاعب داخل المدينة مباشرة؛ لا توجد قائمة توقف اللعب.
- عصا الشاشة اليسرى للمشي وتدوير الكاميرا بالسحب على مساحة اللعب.
- الأزرار اليمنى: الركض، القفز، والتفاعل مع الأبواب والسيارات.
- على لوحة مفاتيح: WASD أو الأسهم للحركة، Shift للركض، Space للقفز، وE للتفاعل.
- المدينة تحتوي على شوارع وأرصفة ومبانٍ ومحلات يمكن دخولها، مشاة، سيارات، خردة قابلة للجمع، و120,000 نقطة تفاصيل أرضية.

## البناء

تحتاج JDK 17 وAndroid SDK Platform 34 وNDK 26.1.10909125 وCMake 3.22.1:

```sh
cd android
./gradlew assembleDebug
```

الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`. سير عمل GitHub Actions يبني APK وينشره كملف إصدار عند الدفع إلى فرع العمل.
