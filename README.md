# MFA 1 – الجزء الأول

لعبة عالم مفتوح سعودية ثلاثية الأبعاد، تعمل حالياً كتطبيق ويب قابل للتشغيل على الكمبيوتر والجوال. المشروع مبني بـ Three.js وVite، ومهيأ للتغليف عبر Capacitor على Android. لا توجد موسيقى؛ المؤثرات الصوتية الإجرائية اختيارية ومتولدة أثناء اللعب.

## تشغيل اللعبة

```sh
npm install
npm run dev
```

افتح عنوان Vite المعروض. للإنتاج:

```sh
npm run build
```

## ما يتضمنه النموذج الحالي

- مدينة إجرائية موسعة بمساحة لعب تقارب 768×768 متراً، 12×12 قطع عمرانية (144 مبنى)، شبكة شوارع، واجهات محلات، مبانٍ خاصة، نخيل وإنارة ولوحات.
- 120,000 نقطة هندسية فعلية لتفاصيل دقيقة على الشوارع والأرصفة، تُرسم كمجموعة نقاط واحدة على GPU؛ العدد ظاهر في HUD أثناء اللعب.
- مبانٍ ومحلات يمكن دخولها مع أبواب متحركة وديكورات داخلية إجرائية.
- شخصية بملابس سعودية وحركة مشي/ركض/قفز، مشاة وبائعون، سيارات قابلة للقيادة وحركة مرور.
- مهام قصة قصيرة، وظائف توصيل/تاكسي/محل، متاجر، نقاط تفاعل، صحة وجوع ونقود، وخردة قابلة للجمع.
- تحكم لوحة مفاتيح وواجهة لمس، خريطة مصغرة، حوارات وواجهة عربية RTL.
- نواة C++ مستقلة في `native/` لبداية توسيع المحاكاة على Android. لم تُربط بعد بواجهة JavaScript أو JNI.

## تغليف Android

ملف `capacitor.config.json` جاهز. يتطلب إخراج APK تثبيت JDK وAndroid SDK/Android Studio، ثم:

```sh
npx cap add android
npm run build
npx cap sync android
npx cap open android
```

لإنشاء APK debug بعد تثبيت JDK وAndroid SDK/NDK:

```sh
npm run android:apk
```

الناتج المتوقع: `android/app/build/outputs/apk/debug/app-debug.apk`. بيئة التطوير الحالية لا تحتوي على JDK أو Android SDK/NDK، لذلك تعذر إخراج APK قابل للتثبيت هنا. حجم APK النهائي يعتمد على الأصول الفعلية وتهيئة البناء؛ لا تُحشى ملفات عشوائية لرفع الحجم. محتوى المدينة الحالي مولّد برمجياً، ولذلك حجم ملفات الويب صغير نسبياً ولا يعكس حجم لعبة تجارية نهائية.
